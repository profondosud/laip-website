## 📝 NOTE IMPLEMENTAZIONE

1. **Mantenere coerenza visiva** con sito LAIP principale
2. **Font**: Poppins (headings), Inter (body)
3. **Icons**: Font Awesome 6.4.0 CDN
4. **Nessun tracciamento/analytics** su bozze (privacy policy)
5. **Auto-delete**: Implementare script che cancella file dopo 24h
6. **Responsive first**: Testare su mobile, tablet, desktop

## 🚀 USO VELOCE

**Per generare una nuova bozza:**

1. Copia questo template
2. Compila tutte le sezioni `[...]`
3. Usa uno script/generatore per convertire in HTML
4. Testa responsive e link funzionanti
5. Invia al cliente

**Tempo stimato**: 15-20 minuti per bozza completa
